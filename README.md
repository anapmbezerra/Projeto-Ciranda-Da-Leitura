## Projeto Ciranda da Leitura

O Ciranda da Leitura é uma aplicação web desenvolvida para incentivar a leitura comunitária através da troca e doação de livros. O projeto busca conscientizar a população sobre a importância da leitura e facilitar o acesso a obras literárias e didáticas na comunidade.

## Funcionalidades

Conscientização: Apresenta dados estatísticos e materiais sobre o panorama da leitura no Brasil.

Mídia Informativa: Vídeo incorporado detalhando os benefícios da leitura regular.

Formulário Dinâmico: Cadastro simples para voluntários que desejam doar ou trocar livros.

Feedback em Tempo Real: Confirmação instantânea após o preenchimento do formulário utilizando JavaScript para manipular o DOM.

Interface Responsiva: Design agradável e adaptado para navegação simples.

 ## Tecnologias Utilizadas

HTML5: Estruturação semântica da página (tags como <header>, <main>, <section>, <article>, <aside>, <footer>, entre outras).

CSS3: Estilização personalizada, layout responsivo com Flexbox, estilização de tabelas e formulários.

JavaScript (ES6): Manipulação de eventos, validação de dados de entrada e atualização dinâmica da interface.
